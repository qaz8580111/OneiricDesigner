# 子弹弹道构型（Shot Pattern）方案

> 用途：新增「一次开火产生几发、以何角度/时序/轨迹飞出」的可扩展维度，让玩家与敌人的普通射击共用同一套弹道构型资源。
> 状态：**已实施**（基础架构 + 7 种构型已落地，落地差异见 11.3；构型词条化已于 2026-09-22 落地，见 11.4；2026-09-23 新增螺旋扫射、双向突刺两种构型，见 11.6；**2026-09-29 起构型改为装备主动技能（主动释放 + 冷却），见 11.9**；决策见第十一节）。
> 关联现有体系：`BulletData`（数据）、`BulletForm`（外观形态）、`BulletEffect`（特效）三层策略资源。

---

## 一、命名：这种功能在业界叫什么

「弹道构型」不是临时造词，业界有成熟叫法，按使用场景从广到窄排列：

| 术语 | 中文 | 适用语境 | 说明 |
|---|---|---|---|
| **Shot Pattern** | 弹道构型 | 通用 Roguelike / 俯视角射击 | 最贴合本项目"一次开火的多发排布"，也是本方案选用的英文名 |
| **Firing Pattern** | 开火模式 | FPS / 双摇杆射击 | 与 Fire Mode 常混用，偏"单发/连发/霰弹"这类离散选择 |
| **Fire Mode** | 开火模式 | 传统枪械 | 单发 / 三连发 / 全自动，语义偏"扣扳机的节奏" |
| **Emission Pattern** | 发射形态 | 通用引擎文档 | 强调"从发射点向外散出的构型" |
| **Bullet Pattern / Danmaku Pattern** | 弹幕构型 | 弹幕游戏（东方等） | 强调敌人弹幕的宏观排布，本项目的"扇形/环形"正是其子集 |
| **Spread / Multishot / Volley / Nova** | 散射 / 多发 / 齐射 / 环形爆发 | 具体构型的通用叫法 | 可作为子类名参考 |

**本项目命名落地约定**（推荐）：

- 概念中文名：**弹道构型**（与既有"外观形态 BulletForm"是两种概念，辨析见第二节）
- 资源基类：`BulletShotPattern`（目录 `scripts/resources/bullet/BulletShotPattern.gd`）
- 子类命名：`<描述>Pattern`，如 `FanSpreadPattern` / `ParallelColumnPattern` / `HeavyExplosivePattern`
- 资源目录：`data/bullet/pattern/`（与 `data/bullet/effect/`、`data/bullet/form/` 并列）
- 资源文件：`<name>_pattern.tres`；`pattern_id` 前缀统一 `pattern_`
- 子弹数据插槽：`BulletData.shot_pattern`

## 二、与「外观形态 BulletForm」的职责辨析

**结论：两者是两种不同概念，不建议合并。** 以下为代码实证。

### 2.1 BulletForm 实际在做什么

| 字段 / 方法 | 声明的作用 | 实际消费方 |
|---|---|---|
| `form_id` | 形态唯一标识 | 无逻辑使用（仅调试/命名用途） |
| `collision_radius` | "子弹碰撞半径" | **全项目无人读取（死字段）** |
| `placeholder_color` | 占位贴图颜色 | `apply_visual()` → 写入 `Sprite2D.texture` |
| `placeholder_size` | 占位贴图尺寸 | 同上 |
| `apply_visual(sprite)` | 生成一张纯色 `ImageTexture` 赋给精灵 | [Bullet._apply_bullet_data()](file:///d:/Projects/OneiricDesigner/scripts/entities/Bullet.gd#L210-L219)、[Enemy._perform_attack()](file:///d:/Projects/OneiricDesigner/scripts/entities/Enemy.gd#L849-L861) |

三条硬事实：

1. `data/bullet/form/` 下 **11 个 .tres 全部是基类 `BulletForm` 的实例**，无一个挂子类脚本 → 当前它实际等价于"换颜色的同一种实现"。
2. 子弹碰撞体来自 [Bullet.tscn](file:///d:/Projects/OneiricDesigner/scenes/gameplay/Bullet.tscn#L21-L22) 固定的 `RectangleShape2D 16x16`，**与 form 无关**。
3. 它**完全不参与**"发几发 / 什么角度 / 什么时序 / 什么速度曲线"。

一句话：`BulletForm` = 单发子弹**长什么样**；`BulletShotPattern` = 一次开火**怎么发出去**。

### 2.2 四维对照

| 对照维度 | 外观形态 BulletForm | 弹道构型 BulletShotPattern |
|---|---|---|
| 回答的问题 | 这颗子弹长什么样 | 一次开火产出几发、怎么排 |
| 作用范围 | **单个子弹实例** | **一次开火**（1 → N 发） |
| 生效时机 | 子弹实例化后设置外观 | 开火瞬间计算弹道 |
| 现有字段 | 颜色、贴图尺寸（+ 未使用的 `collision_radius`） | 发数、张角、偏移、延迟、伤害/速度/缩放系数 |
| 是否影响伤害 | 否 | 间接（通过 `damage_mult` 分摊） |
| 组合关系 | **正交**：11 种外观 × N 种构型 可任意搭配 | 同左 |
| 能否单独复用 | 能（只换颜色不动构型） | 能（只换构型不动颜色） |

### 2.3 合并的代价（为什么不建议合）

1. **维度正交被破坏**：合并后"三列平行"会被迫绑定某种颜色/尺寸，同一个构型无法复用到不同敌人（archer 蓝弹 / firemage 红弹 都得各建一份）。
2. **作用域不同**：构型作用域是"一次开火"，外观作用域是"单发实例"。合并后一个资源要同时承担两种生命周期，语义混乱、状态难维护。
3. **数据复用率下降**：8 个敌人各有不同颜色但都想用"扇形构型"——合并要建 8 个副本；分立只需 **1 个构型 + 8 个外观**。

### 2.4 两者确实存在的一处重叠（已确认归属）

`BulletForm.collision_radius` 的字段语义（"子弹碰撞半径"）与弹道构型的 `scale_mult`（重弹整体放大）在概念上有重叠：

- **现状**：`collision_radius` 无人使用，碰撞体固定 16x16，所以"大子弹"目前无法靠配置实现；
- **已确认（2026-09-22）**：碰撞尺寸归给构型的 `scale_mult`——节点缩放会带动子 `CollisionShape2D` 同步变大，重弹的视觉与判定一起放大；`collision_radius` 作为死字段保留，后续清理时一并删除。

> 由此确定：**弹道构型的 `scale_mult` 是子弹碰撞尺寸的唯一配置来源**，外观形态 `BulletForm` 只负责颜色与贴图尺寸。

## 三、现状诊断（为什么需要新增这一层）

当前"打几发、什么角度"是**硬编码**在各发射方内部的，没有任何可挂载资源：

| 位置 | 现状 | 问题 |
|---|---|---|
| [Player._shoot()](file:///d:/Projects/OneiricDesigner/scripts/entities/Player.gd#L640-L656) | 只播音效/动画，`shot.emit(位置, 方向, 子弹数据)` | 玩家永远单发直线，无法通过数据扩展 |
| [GameWorld._on_player_shot()](file:///d:/Projects/OneiricDesigner/scripts/entities/GameWorld.gd#L685-L726) | 实例化 1 发子弹的完整流程 | 发射流程与"发几发"耦合，无构型概念 |
| [Enemy._perform_attack()](file:///d:/Projects/OneiricDesigner/scripts/entities/Enemy.gd#L779-L864) | 再写一遍实例化 1 发子弹的流程 | 与玩家侧重复；且各自维护碰撞层等细节 |
| `Enemy._skill_spread_shot` / `_skill_nova_burst` / `_skill_barrage` | 在技能内联写死扇形 / 环形 / 连发 | 构型代码散落且不可复用，玩家拿不到 |

**结论**：玩家与敌人的"普通射击"完全可以直接共用一套弹道构型资源，先抽象普通射击，技能弹幕可作为后续收益（不在本次范围）。

## 四、架构设计

### 4.1 新增第四维度（策略模式，与既有三层并列）

```
BulletData（子弹数据）
 ├── damage / speed              数值
 ├── form     : BulletForm           外观形态（长什么样、贴图多大）  ← 已有
 ├── effects  : Array[BulletEffect]  命中/飞行特效                  ← 已有
 └── shot_pattern : BulletShotPattern ★新增：弹道构型（发几发、怎么排）
```

**关键设计：构型只负责"算弹道"，不负责"造子弹"**。即 `BulletShotPattern` 返回一组**弹道描述（ShotSpec）**，由**统一发射器**去实例化子弹。这样：

- 玩家、敌人、以及未来的技能/道具，都复用同一个发射器 → 一次实现，两处免费；
- 构型是纯数据计算，可单元测试、可叠加、无副作用；
- 新增一种构型 = 新增 1 个 `.gd` + 1 个 `.tres`，**调用方零改动**。

### 4.2 弹道描述 ShotSpec（Dictionary）

| 键 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `direction` | Vector2 | 必填 | 该发子弹的飞行方向（未归一化也可，发射器会归一化） |
| `offset` | Vector2 | `Vector2.ZERO` | 相对发射原点的**世界坐标偏移**（平行列的横向错位靠它实现） |
| `delay` | float | `0.0` | **距开火时刻**的延迟秒数（连发用 `i * interval`，不是累加） |
| `damage_mult` | float | `1.0` | 该发伤害系数（扇形/平行列分摊总伤害用） |
| `speed_mult` | float | `1.0` | 该发速度系数（重弹变慢用） |
| `scale_mult` | float | `1.0` | 该发整体缩放（**子弹碰撞尺寸的唯一配置来源**，视觉与碰撞体同步放大，重弹用） |
| `extra_effects` | Array | `[]` | 仅本发附加的特效（重弹挂爆炸用） |

### 4.3 核心接口草案（新建 `scripts/resources/bullet/BulletShotPattern.gd`）

```gdscript
## BulletShotPattern.gd - 子弹弹道构型资源基类
## 职责：定义"一次开火产出哪些弹道"，作为弹道构型系统的扩展基类
## 继承：Resource（可在编辑器中创建 .tres 配置）
## 设计意图：策略模式——每个构型是独立 Resource 子类，挂载在 BulletData.shot_pattern，
##           由统一发射器（GameWorld.spawn_shot_pattern）读取 ShotSpec 列表后实例化子弹；
##           构型只算弹道不造子弹，从而被玩家与敌人的普通射击无条件复用
## 被引用方：BulletData.shot_pattern、data/bullet/pattern/ 下的 .tres
class_name BulletShotPattern
extends Resource

## 构型唯一标识（用于日志、调试和按 ID 查找）
@export var pattern_id: String = "single"

## 显示名（装备主动技能展示用，如"扇形散射"；为空时调用方回退 pattern_id）
@export var display_name: String = ""

## 说明文案（装备主动技能 tooltip 用）
@export var description: String = ""

## 计算本次开火的全部弹道（扩展插槽，子类必须重写）
## 参数：origin - 发射原点（世界坐标，供构型计算偏移参考）
##       direction - 瞄准方向（未归一化）（中心弹道基准）
##       bullet_data - 承载本构型的子弹数据（供构型读取伤害/速度做分摊）
## 返回：ShotSpec 字典数组（见 4.2，元素顺序即发射顺序）
func build_shots(origin: Vector2, direction: Vector2, bullet_data: Resource) -> Array:
    ## 默认实现：单发直线（与当前硬编码行为等价，作为所有未配置构型的兜底）
    return [_shot(direction)]

## 构造一条弹道描述（子类复用，避免手工拼字典漏键）
## 说明：extra_effects 不在此处参数化，子类按需 spec["extra_effects"].append(...)
func _shot(
    direction: Vector2,
    offset: Vector2 = Vector2.ZERO,
    delay: float = 0.0,
    damage_mult: float = 1.0,
    speed_mult: float = 1.0,
    scale_mult: float = 1.0
) -> Dictionary:
    return {
        "direction": direction,
        "offset": offset,
        "delay": delay,
        "damage_mult": damage_mult,
        "speed_mult": speed_mult,
        "scale_mult": scale_mult,
        "extra_effects": [],
    }
```

> 按工作区规则，子类以 `extends "res://scripts/resources/bullet/BulletShotPattern.gd"` 路径方式继承（避免全局类缓存未就绪时 `Could not find base class`，同 `SplitEffect`）。

### 4.4 BulletData 新增插槽

在 [BulletData.gd](file:///d:/Projects/OneiricDesigner/scripts/resources/bullet/BulletData.gd) 增加（与 `form` / `effects` 同构）：

```gdscript
## 弹道构型资源类
const BulletShotPatternClass = preload("res://scripts/resources/bullet/BulletShotPattern.gd")

## 弹道构型（决定一次开火产出几发、以何角度/时序/偏移飞出）
## 为空时使用默认单发直线构型（保证现存 11 个 BulletData.tres 行为零变化）
@export var shot_pattern: BulletShotPatternClass = null

## 默认弹道构型缓存（懒加载，避免每次调用都新建对象）
var _default_shot_pattern: BulletShotPatternClass = null

## 获取实际弹道构型（扩展插槽）：未配置时回退默认单发直线
func get_final_shot_pattern() -> BulletShotPatternClass:
    if shot_pattern != null:
        return shot_pattern
    if _default_shot_pattern == null:
        _default_shot_pattern = BulletShotPatternClass.new()
    return _default_shot_pattern
```

## 五、统一发射器（玩家/敌人共用）

在 [GameWorld.gd](file:///d:/Projects/OneiricDesigner/scripts/entities/GameWorld.gd) 新增两个方法，把"发几发"从"造子弹"里解耦：

```gdscript
## 统一弹道构型发射出口（玩家与敌人的普通射击共用）
## 参数：origin - 发射位置；direction - 瞄准方向；bullet_data - 子弹配置（承载弹道构型）；
##       owner_group - 阵营 "player"/"enemy"（决定碰撞层与同阵营过滤）
func spawn_shot_pattern(origin: Vector2, direction: Vector2,
        bullet_data: BulletDataClass, owner_group: String) -> void:
    var data_to_use: BulletDataClass = bullet_data if bullet_data != null else default_bullet_data
    if data_to_use == null or BULLET_SCENE == null:
        return
    ## 构型计算弹道（构型只读数据，不修改共享 .tres）
    var shots: Array = data_to_use.get_final_shot_pattern().build_shots(origin, direction, data_to_use)
    for spec in shots:
        var delay: float = float(spec.get("delay", 0.0))
        if delay <= 0.0:
            _spawn_one_bullet(spec, data_to_use, owner_group, origin)
        else:
            ## 延迟弹单独协程，不阻塞后续弹道；delay 语义为"距开火时刻"
            _spawn_one_bullet_deferred(spec, data_to_use, owner_group, origin, delay)

## 延迟弹协程：等待 delay 后生成单发（世界已释放则静默退出）
func _spawn_one_bullet_deferred(spec: Dictionary, base_data: BulletDataClass,
        owner_group: String, origin: Vector2, delay: float) -> void:
    await get_tree().create_timer(delay).timeout
    if not is_instance_valid(self):
        return
    _spawn_one_bullet(spec, base_data, owner_group, origin)

## 生成单发子弹（原 _on_player_shot 的实例化流程收敛于此，玩家/敌人共用）
func _spawn_one_bullet(spec: Dictionary, base_data: BulletDataClass,
        owner_group: String, origin: Vector2) -> void:
    var dir: Vector2 = spec.get("direction", Vector2.RIGHT)
    if dir == Vector2.ZERO:
        dir = Vector2.RIGHT
    dir = dir.normalized()
    var bullet: Area2D = BULLET_SCENE.instantiate()
    ## 敌人子弹先禁用碰撞，避免出生瞬间与发射者自身相撞（沿用 Enemy 原有处理）
    if owner_group == "enemy":
        bullet.monitoring = false
        bullet.collision_layer = 8
        bullet.collision_mask = 1
    add_child(bullet)
    bullet.global_position = origin + Vector2(spec.get("offset", Vector2.ZERO))
    ## 重置物理插值：add_child 后传送必须重置，否则子弹从原点滑向目标（视觉bug）
    if bullet.has_method("reset_physics_interpolation"):
        bullet.reset_physics_interpolation()
    ## 按弹道系数派生本发数据（无系数且无额外特效时直接共享，避免深拷贝）
    if bullet.has_method("set_bullet_data"):
        bullet.set_bullet_data(_build_bullet_data(base_data, spec))
    bullet.set_direction(dir)
    bullet.set_owner_group(owner_group)
    ## 整体缩放：CollisionShape2D 为子节点，随节点缩放同步生效
    var scale_mult: float = float(spec.get("scale_mult", 1.0))
    if not is_equal_approx(scale_mult, 1.0):
        bullet.scale = Vector2.ONE * scale_mult
    _bullets.append(bullet)
    bullet.hit.connect(_on_bullet_hit)
    bullet.destroyed.connect(_on_bullet_destroyed.bind(bullet))
    if owner_group == "enemy":
        bullet.monitoring = true

## 按弹道系数派生子弹数据（返回共享或副本）
## 性能：无任何系数改动、无额外特效、原数据无特效时直接共享（只读），复刻原优化
func _build_bullet_data(base: BulletDataClass, spec: Dictionary) -> BulletDataClass:
    var dmg_mult: float = float(spec.get("damage_mult", 1.0))
    var spd_mult: float = float(spec.get("speed_mult", 1.0))
    var extra: Array = spec.get("extra_effects", [])
    var plain: bool = is_equal_approx(dmg_mult, 1.0) and is_equal_approx(spd_mult, 1.0) \
        and extra.is_empty() and base.effects.is_empty()
    if plain:
        return base
    var data: BulletDataClass = base.duplicate()
    if not is_equal_approx(dmg_mult, 1.0):
        ## 伤害保底 1：低伤害弹经系数折算后 int 截断会变 0（同 SplitEffect 处理）
        data.damage = maxi(int(base.damage * dmg_mult), 1)
    if not is_equal_approx(spd_mult, 1.0):
        data.speed = base.speed * spd_mult
    for effect in extra:
        if effect != null:
            data.effects.append(effect)
    return data
```

| # | pattern_id | 类名 | 中文名 | 新增维度 | 默认参数要点 |

### 6.2 各构型实现与参数

#### ① FanSpreadPattern（扇形散射，对应需求例 1）

```gdscript
## 扇形散射：以瞄准方向为中心，在总张角内均匀发射 shot_count 发
extends "res://scripts/resources/bullet/BulletShotPattern.gd"

@export var shot_count: int = 3          ## 单次发射弹数（含中心弹）
@export var spread_angle: float = 30.0    ## 扇形总张角（度）
@export var random_jitter: float = 0.0    ## 每发随机抖动（度，0=不抖）
@export var damage_mult: float = 0.6      ## 单发伤害系数（多发需分摊，防数值膨胀）
@export var speed_mult: float = 1.0

func build_shots(origin: Vector2, direction: Vector2, bullet_data: Resource) -> Array:
    var shots: Array = []
    var base_angle: float = direction.angle()
    var count: int = maxi(shot_count, 1)
    ## 单发时角度步长为 0，避免除以 0
    var step: float = deg_to_rad(spread_angle) / float(count - 1) if count > 1 else 0.0
    var start: float = base_angle - deg_to_rad(spread_angle) * 0.5
    for i in range(count):
        var angle: float = start + step * i
        if random_jitter > 0.0:
            angle += deg_to_rad(randf_range(-random_jitter, random_jitter))
        shots.append(_shot(Vector2(cos(angle), sin(angle)),
            Vector2.ZERO, 0.0, damage_mult, speed_mult, 1.0))
    return shots
```

- 需求例 1 落地：`shot_count=3`、`spread_angle=30.0` → 一发中、一发左偏 15°、一发右偏 15°。

#### ② ParallelColumnPattern（三列平行直线，对应需求例 2）

```gdscript
## 平行列：沿瞄准方向的垂直向量等距错位，各列保持平行同向飞出
extends "res://scripts/resources/bullet/BulletShotPattern.gd"

@export var column_count: int = 3        ## 列数
@export var column_spacing: float = 24.0 ## 相邻列间距（像素）
@export var damage_mult: float = 0.7     ## 单发伤害系数
@export var speed_mult: float = 1.0

func build_shots(origin: Vector2, direction: Vector2, bullet_data: Resource) -> Array:
    var shots: Array = []
    var dir: Vector2 = direction.normalized() if direction != Vector2.ZERO else Vector2.RIGHT
    ## 垂直方向向量：用于把各列横向推开（旋转 90°）
    var side: Vector2 = dir.orthogonal()
    var count: int = maxi(column_count, 1)
    ## 以中心列居中：i=0..n-1 映射到 -(n-1)/2 .. +(n-1)/2
    var center_index: float = float(count - 1) * 0.5
    for i in range(count):
        var offset: Vector2 = side * column_spacing * (float(i) - center_index)
        shots.append(_shot(dir, offset, 0.0, damage_mult, speed_mult, 1.0))
    return shots
```

- 需求例 2 落地：`column_count=3`、`column_spacing=24.0` → 三列平行弹幕，覆盖横向 48px 宽度。

#### ③ HeavyExplosivePattern（重型爆破弹，对应需求例 3）

```gdscript
## 重型爆破弹：单发大体积、降速、高伤，命中后由爆炸特效做范围伤害
## 设计意图：不新增任何爆炸代码——复用现成 ExplosionEffect（ON_HIT），
##           构型只负责"把这发弹调大调重并挂上爆炸特效"
extends "res://scripts/resources/bullet/BulletShotPattern.gd"

const BulletEffectClass = preload("res://scripts/resources/bullet/BulletEffect.gd")

@export var bullet_scale: float = 2.0      ## 体型缩放（视觉+碰撞同步放大）
@export var damage_mult: float = 2.0       ## 直击伤害系数
@export var speed_mult: float = 0.6        ## 速度系数（重弹更慢）
@export var explosion_effect: BulletEffectClass = null  ## 命中爆炸特效（默认挂 explosion_effect.tres）

func build_shots(origin: Vector2, direction: Vector2, bullet_data: Resource) -> Array:
    var spec: Dictionary = _shot(direction, Vector2.ZERO, 0.0,
        damage_mult, speed_mult, bullet_scale)
    if explosion_effect != null:
        ## 仅本发附加爆炸（不改动承载它的 BulletData，避免污染共享 .tres）
        spec["extra_effects"].append(explosion_effect)
    return [spec]
```

- 需求例 3 落地：`.tres` 中 `explosion_effect` 指向 `res://data/bullet/effect/explosion_effect.tres`（该特效 `trigger_type=0` 即 ON_HIT）。
- 若希望爆炸半径随构型单独配置，可再建一个 `heavy_explosion_effect.tres`（同脚本、不同半径/倍率），无需改代码。

#### ④ BurstVolleyPattern（连发点射）

```gdscript
## 连发点射：同一方向连续发射 burst_count 发，用 delay 制造时间序列弹幕
extends "res://scripts/resources/bullet/BulletShotPattern.gd"

@export var burst_count: int = 3         ## 连发发数
@export var burst_interval: float = 0.08 ## 相邻两发间隔（秒）
@export var damage_mult: float = 0.8     ## 单发伤害系数
@export var speed_mult: float = 1.0

func build_shots(origin: Vector2, direction: Vector2, bullet_data: Resource) -> Array:
    var shots: Array = []
    for i in range(maxi(burst_count, 1)):
        ## delay 语义为"距开火时刻"，故用 i*interval 而非累加
        shots.append(_shot(direction, Vector2.ZERO,
            burst_interval * float(i), damage_mult, speed_mult, 1.0))
    return shots
```

#### ⑤ RingNovaPattern（环形爆发）

```gdscript
## 环形爆发：以发射点为圆心 360° 均分发射，用于被围时的清场手段
extends "res://scripts/resources/bullet/BulletShotPattern.gd"

@export var ring_count: int = 6          ## 环形弹数
@export var start_angle_offset: float = 0.0  ## 起始角偏移（度，可让环不总是对齐正右方向）
@export var damage_mult: float = 0.3     ## 单发伤害系数
@export var speed_mult: float = 0.9

func build_shots(origin: Vector2, direction: Vector2, bullet_data: Resource) -> Array:
    var shots: Array = []
    var count: int = maxi(ring_count, 1)
    var step: float = TAU / float(count)                    ## 360° 均分
    var start: float = deg_to_rad(start_angle_offset)
    for i in range(count):
        var angle: float = start + step * float(i)
        shots.append(_shot(Vector2(cos(angle), sin(angle)),
            Vector2.ZERO, 0.0, damage_mult, speed_mult, 1.0))
    return shots
```

#### ⑥ HelixSpiralPattern（螺旋扫射）

```gdscript
## 螺旋扫射：沿瞄准方向起手，按固定间隔逐发递增角度偏移，形成旋转扫射弹道
extends "res://scripts/resources/bullet/BulletShotPattern.gd"

@export var shot_count: int = 5             ## 扫射发数
@export var shot_interval: float = 0.06     ## 相邻两发间隔（秒）
@export var angle_step: float = 10.0        ## 每发角度递增量（度），总张角 = angle_step * (shot_count - 1)
@export var start_angle_offset: float = 0.0 ## 首发起始角偏移（度，相对瞄准方向）
@export var damage_mult: float = 0.5        ## 单发伤害系数（多发需分摊，防数值膨胀）
@export var speed_mult: float = 1.0

func build_shots(origin: Vector2, direction: Vector2, bullet_data: Resource) -> Array:
    var shots: Array = []
    var count: int = maxi(shot_count, 1)
    ## 以瞄准方向为扫射基准角（零向量时 angle() 返回 0，即正右，与统一发射器兜底一致）
    var base_angle: float = direction.angle()
    var start: float = base_angle + deg_to_rad(start_angle_offset)
    var step: float = deg_to_rad(angle_step)
    for i in range(count):
        var angle: float = start + step * float(i)
        ## delay 语义为"距开火时刻"，故用 i*interval 而非累加
        shots.append(_shot(Vector2(cos(angle), sin(angle)),
            Vector2.ZERO, shot_interval * float(i), damage_mult, speed_mult, 1.0))
    return shots
```

- 与既有构型的区别：`fan_spread` 只有角度、`burst_volley` 只有时间，本构型是**两者叠加**——
  首发顺瞄准方向，随后逐发偏转，形成"扇面扫过"的轨迹。
- 与 `burst_volley` 相同的约束：延迟弹的原点取**开火时刻**位置（`_spawn_one_bullet_deferred`
  复用同一 `origin`），所以弹道从开火点呈扇形扫出，而非跟随玩家移动。
- 分摊依据：5 发 ×0.5 的理论上限为 2.5 倍，但扫射轨迹沿 40° 铺开，对移动目标的全中概率低于
  扇形/平行列，故定在 `fan_spread`（全中 1.8）与 `burst_volley`（全中 2.4）之间偏上。

#### ⑦ BipolarThrustPattern（双向突刺）

```gdscript
## 双向突刺：正前方与正后方同时成弹，兼顾输出与背身自保
extends "res://scripts/resources/bullet/BulletShotPattern.gd"

@export var forward_count: int = 2       ## 前向发数（以瞄准方向为中心展开）
@export var forward_spread: float = 12.0 ## 前向总张角（度）
@export var backward_count: int = 1      ## 后向发数（以瞄准方向的反方向为中心展开）
@export var backward_spread: float = 24.0## 后向总张角（度）
@export var damage_mult: float = 0.7     ## 单发伤害系数（多发需分摊，防数值膨胀）
@export var speed_mult: float = 1.0

func build_shots(origin: Vector2, direction: Vector2, bullet_data: Resource) -> Array:
    var shots: Array = []
    var dir: Vector2 = direction.normalized() if direction != Vector2.ZERO else Vector2.RIGHT
    var base_angle: float = dir.angle()
    _append_arc(shots, base_angle, forward_count, forward_spread)         ## 前向扇面
    _append_arc(shots, base_angle + PI, backward_count, backward_spread)  ## 后向扇面（+π 即反方向）
    return shots
```

- 与 `ring_nova` 的区别：环形把伤害摊到 360°（单发仅 ×0.3），本构型只聚焦前后两个方向，
  所以单发系数能保持 ×0.7；后向张角（24°）刻意大于前向（12°），因为后向弹只在被包夹时
  才有价值，需要更宽的拦截面。
- 分摊依据：3 发 ×0.7 = 全中 2.1 倍，与 `parallel_columns` 同档。
- 实现细节：前后两个扇面共用私有助手 `_append_arc(shots, center_angle, count, spread_deg)`，
  发数填 1 时角度步长为 0（避免除以 0），因此 `backward_count` 调到 2 以上也无需改代码。

## 九、风险与注意事项

1. **同阵营过滤**：多发子弹必须逐个 `set_owner_group(owner_group)`，否则环形/平行列会误伤发射者（发射器已统一处理，构型子类不要自行实例化子弹）。
2. **物理插值**：任何新增子弹的代码路径都必须 `reset_physics_interpolation()`（含延迟弹），否则会出现"从原点滑向目标"的视觉 bug。
3. **伤害分摊**：扇形/平行列/环形必须用 `damage_mult < 1` 分摊，否则构型直接变成伤害倍率放大器，破坏平衡（重弹属于"高成本单发"，可 >1）。
4. **延迟弹生命周期**：`_spawn_one_bullet_deferred` 用 `is_instance_valid(self)` 防世界已释放；玩家死亡/切场景时连发未完结的弹会自动作废。
5. **碰撞体缩放**：`scale_mult` 依赖节点缩放带动子 `CollisionShape2D`，若某天碰撞体不是子节点将失效（当前 [Bullet.tscn](file:///d:/Projects/OneiricDesigner/scenes/gameplay/Bullet.tscn) 是子节点，安全）。
6. **性能**：环形 6 发 × 多敌人同时开火会瞬时增加子弹数；`_bullets` 已有上限管理，但需实测帧率（建议环形默认 6 发、连发默认 3 发起步）。
7. **敌人染色**：迁移后对手无 `form` 的敌人子弹 `_body_color` 染色需经 `tint_color` 参数保留，否则近战敌人子弹会统一变成默认弹颜色。
8. **不臆造 API**：`build_shots` 返回原生 `Array[Dictionary]`，`_shot()` 默认参数均为常量，避免 GDScript 默认参数必须为常量表达式的限制。
9. **命名不要混用**：`BulletForm` 一律称**外观形态**，`BulletShotPattern` 一律称**弹道构型**；两者是正交维度，不互相替代。

### 11.8 构型平衡与伤害守恒分配（2026-09-28 已实施）

**背景**：弹道构型是"直接拾取、单槽位整体替换"，其中 `ring_nova`（环形爆发）因 360° 全向覆盖、
零瞄准即可贴身清场，被判定为"拾取即毕业"。经讨论选定**方案三·构型平衡**，分两层落地：
层 1 修正伤害口径（1A 伤害守恒分配），层 2 下调环形数值。

**层 1 · 伤害守恒分配（1A 口径修正）**：

- 旧口径缺陷：每发各自 `maxi(int(基础伤害 × 系数), 1)`，而基础伤害是整数（玩家默认 2），
  于是 `2 × 0.6 / 0.7 / 0.8` 一律被 `int` 截断成 `1`——扇形/平行列/连发/双向"多打中就有收益"
  的设计完全失效（3 发也只等于 1 发的伤害），构型差异被整数截断抹平。
- 新口径：[GameWorld.gd](file:///d:/Projects/OneiricDesigner/scripts/entities/GameWorld.gd) 新增
  `_assign_conserved_damage()`，在生成子弹前按系数权重把**整轮总伤**
  `max(round(基础伤害 × Σ各发系数), 发数)` 拆成整数（第一轮 floor、第二轮最大余数法补足，每发保底 1），
  写回 `spec["damage_override"]`；`_build_bullet_data()` 优先采用该预算，无预算时回退旧折算
  （单发构型直接跳过，零行为变化）。

**层 2 · 环形数值下调**：`ring_nova` 由 `8 发 / ×0.5` 调为 `6 发 / ×0.3`
（[ring_nova_pattern.tres](file:///d:/Projects/OneiricDesigner/data/bullet/pattern/ring_nova_pattern.tres)
与 [RingNovaPattern.gd](file:///d:/Projects/OneiricDesigner/scripts/resources/bullet/pattern/RingNovaPattern.gd)
默认值同步）。**注意**：整数伤害下 `×0.3` 对总量无效（每发保底 1），真正的杠杆是**发数**。

**落地后各构型整轮总伤（基础伤害 2 的玩家默认弹）**：

| pattern_id | 发数 | 整轮总伤 | 倍率 | 说明 |
|---|---|---|---|---|
| `single` | 1 | 2 | 1.0× | 基线 |
| `fan_spread` | 3 | 4 | 2.0× | 名义 ×0.6 分摊，整数化后实为 2.0× |
| `parallel_columns` | 3 | 4 | 2.0× | 同扇形 |
| `bipolar_thrust` | 3 | 4 | 2.0× | 前后覆盖，同档 |
| `heavy_explosive` | 1 | 4 | 2.0× | 单发 + 范围伤害 |
| `burst_volley` | 3 | 5 | 2.5× | 时间维度上限 |
| `helix_spiral` | 5 | 5 | 2.5× | 时间 × 角度，40° 扫射对移动目标全中概率低 |
| `ring_nova` | 6 | 6 | 3.0× | 整轮总量仍为全场最高，但 360° 弹道对单体通常只中 1 发（0.5×/目标） |

**兼容性**：`data/` 下**无任何 `.tres` 配置 `shot_pattern`**（敌人普攻均为单发），
守恒分配只在多发构型生效，敌人链路不受影响；单发构型跳过分配、`_build_bullet_data()` 保留旧折算回退，
未配置构型的回归行为零变化。

**仍待观察**：环形 6 发整轮仍为全场最高（3.0×）；若实机手感偏强，可再降为 **5 发**（2.5×，
与连发/螺旋持平，但弹幕间距由 60° 变 72°，被围时漏怪概率上升）。

### 11.9 构型改为装备主动技能（2026-09-29 已实施）

**背景**：装备化重构（四大成长维度——基础属性 / 特效 / 护盾 / 弹道构型——全部聚合进「装备」）将构型
