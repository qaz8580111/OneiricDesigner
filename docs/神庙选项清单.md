# 神庙选项清单

## 一、神庙机制概述

| 项目 | 说明 |
|------|------|
| 出现方式 | 高级怪死亡时 1% 概率生成，全局同时仅一座 |
| 出现位置 | 高级怪死亡位置 |
| 交互方式 | 玩家靠近后按 E 进入神庙 |
| 进入规则 | 进入神庙后游戏暂停，关闭面板后恢复 |
| 消失规则 | 选定选项 → 效果应用 → **展示结果反馈** → 玩家确认后，神庙伴随消散特效消失 |
| 取消规则 | 进入选项面板后可按返回键（手柄B/键盘ESC）取消，神庙**不消失**，可再次进入 |
| 替换规则 | 新神庙出现时，未进入的旧神庙立即消散 |
| 选择方式 | 支持 LT/RT（扳机）或方向键左右选择，A/确认键选定，B/ESC 取消 |
| 选项加载 | 扫描 `data/temple/*.tres` 数据驱动，新增选项无需改代码 |
| 条件呈现 | 全部选项恒显示；碎片不足、无可强化装备、无融合材料等前置条件不满足的选项「置灰不可选」，而非隐藏 |
| 结果反馈 | 强化/融合等结果随机的选项，应用后切到**结果反馈视图**展示"哪件装备被强化/融合出了什么"，玩家确认后才关闭面板 |
| 装备化定位 | 神庙只作用于**已装备装备**（强化）或**背包内同槽位装备**（融合），不再直接强化"独立技能书/属性词条" |

## 二、选项清单

神庙共 2 种选项（后续可继续扩展）：

### 1. 强化装备（随机强化已装备装备）

| 项目 | 内容 |
|------|------|
| 类型 | 装备强化（`EnhanceEquipmentTempleOption`） |
| 是否赌博 | 是（强化目标随机） |
| 效果 | 从**全部已装备装备**的「属性词条 / 被动特效 / 主动技能 / 护盾」中随机抽一项强化： |
| | · 属性词条：数值 ×(1 + 0.2)（即 +20%） |
| | · 被动特效：叠层 +1（`add_stack()`，可突破常规上限） |
| | · 主动技能：冷却 ×(1 - 0.2)（缩短 20%，下限 1.0 秒） |
| | · 护盾：叠层 +1（`Player.boost_shield_stack(1)`，可突破 3 层上限） |
| 结果反馈 | 应用后展示"强化成功！{稀有度+槽位} · 强化的具体数值"（如"强化成功！\n史诗武器\n属性「攻击力 +12%」"） |
| 消耗 | 梦境碎片，累加计价（第1次 400、第2次 500、第3次 600，每次 +100） |
| 可选条件 | 至少有一件已装备装备携带可强化项（`UpgradeManager.has_enhanceable_equipped()`） |
| 失败条件 | 无可强化目标、或碎片不足时应用失败，神庙保留不消失 |
| 实现方式 | `UpgradeManager.enhance_random_equipped_equipment()`（改数值后 `EquipmentComponent.equip()` 原地重穿刷新）+ `consume_temple_boost` |
| 主题色 | 绿 `Color(0.35, 1.0, 0.55)` |

### 2. 融合装备（背包同槽位 3 件融合）

| 项目 | 内容 |
|------|------|
| 类型 | 装备融合（`FuseEquipmentTempleOption`） |
| 是否赌博 | 是（结果概率分布） |
| 材料选取 | **背包中自动选取**：取"件数最多且 ≥3"的槽位，再取该槽位**稀有度最低的 3 件**（同稀有度保持原背包顺序） |
| 结果概率 | · **30%「更好」**：产出优于三件材料中任意一件（以材料最高稀有度为保底生成，词条数值再 ×1.1） |
| | · **30%「更差或持平」**：无保底常规生成，可能不如材料或与之相当 |
| | · **40%「融合失败」**：无产出，材料照常消耗 |
| 稀有度提升 | 仅「更好」分支内再 roll 一次：`提升概率 = 基准 0.10 + Σ(三件材料稀有度权重)`，封顶 0.60；命中则产出稀有度下限 +1（最高史诗） |
| | 材料稀有度权重（普通/稀有/史诗）：`0.02 / 0.06 / 0.12`，材料越稀有越易提升稀有度 |
| 材料处理 | 无论成败，3 件材料**全部消耗** |
| 消耗 | 梦境碎片 **200**（`UpgradeManager.FUSE_DREAM_COST`，材料之外额外消耗） |
| 结果反馈 | 展示"融合大成功/融合完成，结果平平/融合失败……三件材料已消耗"+（产出时）产出装备的稀有度槽位与词条/被动/主动/护盾明细 |
| 可选条件 | 背包中存在某槽位装备 ≥3 件（`UpgradeManager.can_fuse_equipment()`）**且梦境碎片 ≥200** |
| 实现方式 | `UpgradeManager.fuse_equipment()`（内部 `_collect_fuse_materials` 选材、`_fuse_make_better`/`_fuse_make_worse_or_same` 产出、`BackpackComponent` 增减）；梦境碎片由 `FuseEquipmentTempleOption.apply()` 经 `consume_fuse_cost()` 先行扣除，融合未执行则退还 |
| 主题色 | 粉紫 `Color(1.0, 0.55, 0.9)` |

## 三、选项分类说明

| 分类 | 选项 | 特点 |
|------|------|------|
| 强化式 | 强化装备 | 作用于已装备装备，随机选一类数值提升，可突破常规上限，消耗累加计价 |
| 融合式 | 融合装备 | 消耗背包同槽位 3 件材料 + 200 梦境碎片，随机产出（可能更好/持平或更差/失败），材料无论成败均消耗 |

## 四、与常规等级上限的区别

| 强化来源 | 能否突破上限 |
|----------|-------------|
| 拾取掉落 / 商店购买 / 开局赠送 | 不能（装备生成时词条/特效/护盾层数按常规模型 roll 出） |
| 神庙「强化装备」 | 能（属性 ×1.2 / 特效叠层 +1 / 护盾层数突破 3 层，均不封顶；主动技能冷却缩短，下限 1 秒） |
| 神庙「融合装备」 | 可能（"更好"分支以材料最高稀有度为保底；roll 中稀有度提升时产出稀有度更高） |
