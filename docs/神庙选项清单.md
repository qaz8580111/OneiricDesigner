# 神庙选项清单

## 一、神庙机制概述

| 项目 | 说明 |
|------|------|
| 出现方式 | 高级怪死亡时 1% 概率生成，全局同时仅一座 |
| 出现位置 | 高级怪死亡位置 |
| 交互方式 | 玩家靠近后按 E 进入神庙 |
| 进入规则 | 进入神庙后游戏暂停，关闭面板后恢复 |
| 消失规则 | 仅在「选择一个选项且效果生效」后，神庙伴随消散特效消失 |
| 取消规则 | 进入选项面板后可按返回键（手柄B/键盘ESC）取消，神庙**不消失**，可再次进入 |
| 替换规则 | 新神庙出现时，未进入的旧神庙立即消散 |
| 选择方式 | 支持 LT/RT（扳机）或方向键左右选择，A/确认键选定，B/ESC 取消 |
| 选项加载 | 扫描 `data/temple/*.tres` 数据驱动，新增选项无需改代码 |
| 条件呈现 | 全部选项恒显示；碎片不足或前置条件不满足的选项「置灰不可选」，而非隐藏 |

## 二、选项清单

神庙共 4 种选项，其中 1~3 为**固定 +1 级强化（可突破上限、不封顶）**，均消耗梦境碎片且消耗逐次累加。

### 1. 强化属性（属性强化）

| 项目 | 内容 |
|------|------|
| 类型 | 属性强化（AttributeBoostTempleOption） |
| 是否赌博 | 是（强化目标随机） |
| 效果 | 随机选中一个已拥有的属性类词条，等级 +1 级 |
| 突破上限 | 可突破 5 级上限，不封顶 |
| 消耗 | 梦境碎片，累加计价（第1次 400、第2次 500、第3次 600，每次 +100） |
| 失败条件 | 当前无已拥有属性类词条、或碎片不足时应用失败，神庙保留不消失 |
| 实现方式 | `UpgradeManager.boost_random_attribute(1)` + `consume_temple_boost` |
| 主题色 | 绿 `Color(0.35, 1.0, 0.55)` |

### 2. 强化技能（技能强化）

| 项目 | 内容 |
|------|------|
| 类型 | 技能强化（RandomSkillTempleOption） |
| 是否赌博 | 是（强化目标随机） |
| 效果 | 随机选中一个已拥有的技能类词条（子弹特效），等级 +1 级 |
| 突破上限 | 可突破 5 级上限，不封顶 |
| 消耗 | 梦境碎片，累加计价（第1次 400、第2次 500、第3次 600，每次 +100） |
| 失败条件 | 当前无已拥有特效技能、或碎片不足时应用失败，神庙保留不消失 |
| 实现方式 | `UpgradeManager.boost_random_skill(1)` + `consume_temple_boost` |
| 主题色 | 橙 `Color(0.9, 0.55, 0.25)` |

### 3. 强化护盾（护盾强化）

| 项目 | 内容 |
|------|------|
| 类型 | 护盾强化（RandomShieldTempleOption） |
| 是否赌博 | 是（前提依赖是否已装备护盾） |
| 效果 | 当前装备护盾叠层 +1 层 |
| 突破上限 | 可突破 3 层上限，不封顶 |
| 消耗 | 梦境碎片，累加计价（第1次 400、第2次 500、第3次 600，每次 +100） |
| 失败条件 | 未装备护盾、或碎片不足时应用失败，神庙保留不消失 |
| 实现方式 | `player.boost_shield_stack(1)` + `consume_temple_boost` |
| 主题色 | 蓝 `Color(0.35, 0.65, 1.0)` |

### 4. 融合技能（技能融合）

| 项目 | 内容 |
|------|------|
| 类型 | 技能融合（FuseSkillTempleOption） |
| 是否赌博 | 是（融合目标随机） |
| 可选条件 | 碎片 ≥ 1500 且已持有至少 2 个技能类词条才可选；碎片 < 1500 时选项置灰（仍显示） |
| 效果 | 随机融合两个已拥有的技能类词条，效果叠加并释放一个技能格子 |
| 融合等级 | 取两个技能中较高的等级 |
| 消耗 | 固定消耗 1500 梦境碎片 |
| 图标 | 金色边框，内容显示「融」字 |
| 唯一性 | 玩家仅保留一个融合技能；再次融合会替换前一个融合技能 |
| 不可被强化 | 融合技能不会被「强化技能」选项强化（源技能已移出词条栈） |
| 失败条件 | 已拥有特效技能不足 2 个、或碎片不足时应用失败，神庙保留不消失 |
| 实现方式 | `UpgradeManager.fuse_random_skills()` |
| 主题色 | 金 `Color(1.0, 0.85, 0.2)` |

## 三、选项分类说明

| 分类 | 选项 | 特点 |
|------|------|------|
| 赌博式（is_gamble = true） | 强化属性、强化技能、强化护盾、融合技能 | 效果目标随机，可突破常规等级上限 |

## 四、与常规等级上限的区别

| 强化来源 | 能否突破上限 |
|----------|-------------|
| 三选一拾取 / 商店购买 / 开局授予 | 不能（技能类最高 5 种、属性类最高 3 种，等级最高 5 级） |
| 神庙「强化属性」 | 能（属性类等级突破 5 级，不封顶） |
| 神庙「强化技能」 | 能（技能类等级突破 5 级，不封顶） |
| 神庙「强化护盾」 | 能（护盾层数突破 3 层，不封顶） |
| 神庙「融合技能」 | 能（融合等级取两技能较高值，效果叠加，释放技能格子） |
