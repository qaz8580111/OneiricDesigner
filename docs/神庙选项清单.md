# 神庙选项清单

## 一、神庙机制概述

| 项目 | 说明 |
|------|------|
| 出现方式 | 高级怪死亡时 1% 概率生成，全局同时仅一座 |
| 出现位置 | 高级怪死亡位置 |
| 交互方式 | 玩家靠近后按 E 进入神庙 |
| 进入规则 | 进入神庙后游戏暂停，关闭面板后恢复 |
| 消失规则 | 仅在「选择一个选项且效果生效」后，神庙伴随消散特效消失 |
| 取消规则 | 进入选项面板后可按返回键（手柄B/键盘ESC）取消，神庙**不消失**，可再次进入 |
| 替换规则 | 新神庙出现时，未进入的旧神庙立即消散 |
| 选择方式 | 支持 LT/RT（扳机）或方向键左右选择，A/确认键选定，B/ESC 取消 |
| 选项加载 | 扫描 `data/temple/*.tres` 数据驱动，新增选项无需改代码 |
| 条件呈现 | 全部选项恒显示；碎片不足、无强化目标或背包已满等前置条件不满足的选项「置灰不可选」，而非隐藏 |
| 装备化定位 | 神庙只强化**已穿戴装备**的属性/特效/护盾，并可**求购一件随机装备**；不再直接强化"独立技能书/属性词条" |

## 二、选项清单

神庙共 4 种选项，装备化重构后语义如下：
1~3 为**对已穿戴装备的随机强化**（可突破常规词条/护盾上限，不封顶），消耗梦境碎片且消耗逐次累加；
第 4 项为**定购一件随机装备**（固定价格，不受累加计价影响）。

### 1. 强化装备属性（装备词条强化）

| 项目 | 内容 |
|------|------|
| 类型 | 装备词条强化（EquipmentAffixTempleOption） |
| 是否赌博 | 是（强化目标随机） |
| 效果 | 从全部已穿戴装备的词条中随机选一条，其数值 ×(1 + 0.2)（即 +20%） |
| 突破上限 | 可突破常规词条数值上限，不封顶（每次再 ×1.2） |
| 消耗 | 梦境碎片，累加计价（第1次 400、第2次 500、第3次 600，每次 +100） |
| 可选条件 | 至少有一件已穿戴装备带有词条（`has_boostable_equipment_affix()`） |
| 失败条件 | 无可强化词条、或碎片不足时应用失败，神庙保留不消失 |
| 实现方式 | `UpgradeManager.boost_random_equipment_affix()`（改词条后 `EquipmentComponent.equip()` 原地刷新）+ `consume_temple_boost` |
| 主题色 | 绿 `Color(0.35, 1.0, 0.55)` |

### 2. 强化装备特效（装备特效强化）

| 项目 | 内容 |
|------|------|
| 类型 | 装备特效强化（EquipmentEffectTempleOption） |
| 是否赌博 | 是（强化目标随机） |
| 效果 | 从全部已穿戴装备的子弹特效中随机选一个，叠层 +1 级 |
| 突破上限 | 可突破常规特效 5 级上限，不封顶 |
| 消耗 | 梦境碎片，累加计价（第1次 400、第2次 500、第3次 600，每次 +100） |
| 可选条件 | 至少有一件已穿戴装备带有特效（`has_boostable_equipment_effect()`） |
| 失败条件 | 无可强化特效、或碎片不足时应用失败，神庙保留不消失 |
| 实现方式 | `UpgradeManager.boost_random_equipment_effect()`（`effect.add_stack()` 后 `EquipmentComponent.equip()` 刷新）+ `consume_temple_boost` |
| 主题色 | 橙 `Color(0.9, 0.55, 0.25)` |

### 3. 强化护盾（护盾强化）

| 项目 | 内容 |
|------|------|
| 类型 | 护盾强化（RandomShieldTempleOption） |
| 是否赌博 | 是（前提依赖是否已装备护盾） |
| 效果 | 当前装备护盾叠层 +1 层 |
| 突破上限 | 可突破 3 层上限，不封顶 |
| 消耗 | 梦境碎片，累加计价（第1次 400、第2次 500、第3次 600，每次 +100） |
| 失败条件 | 未装备护盾、或碎片不足时应用失败，神庙保留不消失 |
| 实现方式 | `player.boost_shield_stack(1)` + `consume_temple_boost` |
| 主题色 | 蓝 `Color(0.35, 0.65, 1.0)` |

### 4. 求购装备（定购随机装备）

| 项目 | 内容 |
|------|------|
| 类型 | 定购装备（PurchaseEquipmentTempleOption） |
| 是否赌博 | 否（固定价格，生成结果随机） |
| 效果 | 生成一件随机装备（槽位/稀有度/词条/特效随机），直接放入背包 |
| 价格 | 固定消耗 **500** 梦境碎片（`UpgradeManager.PURCHASE_EQUIPMENT_COST`），**不参与累加计价** |
| 可选条件 | 碎片 ≥ 500 且背包未满，否则选项置灰（仍显示） |
| 归还兜底 | 扣款后若生成/入库失败，自动退还 500 碎片，保证玩家不白花钱 |
| 实现方式 | `UpgradeManager.grant_random_equipment()`（内部调 `generate_equipment()` + `Player.add_equipment_to_backpack`） |
| 主题色 | 金 `Color(1.0, 0.85, 0.2)` |

## 三、选项分类说明

| 分类 | 选项 | 特点 |
|------|------|------|
| 赌博式（is_gamble = true） | 强化装备属性、强化装备特效、强化护盾 | 强化目标随机，可突破常规上限，消耗累加计价 |
| 定购式（is_gamble = false） | 求购装备 | 固定价格、结果随机，不累加计价 |

## 四、与常规等级上限的区别

| 强化来源 | 能否突破上限 |
|----------|-------------|
| 拾取掉落 / 商店购买 / 开局赠送 | 不能（装备生成时词条/特效/护盾层数按常规模型 roll 出） |
| 神庙「强化装备属性」 | 能（词条数值每次 ×1.2，不封顶） |
| 神庙「强化装备特效」 | 能（特效叠层每次 +1，不封顶） |
| 神庙「强化护盾」 | 能（护盾层数突破 3 层，不封顶） |
| 神庙「求购装备」 | 不涉及强化，直接产出一件新装备 |
