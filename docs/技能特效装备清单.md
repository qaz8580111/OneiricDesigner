# 技能 / 特效 / 装备清单（图标制作参考）

> 用途：制作技能图标 icon 的完整对照表。技能 ID 是程序唯一契约，图标文件建议以 ID 命名。
> 数据来源：`data/upgrades/*.tres`（21 个升级词条）、`data/equipment/*.tres`（4 件护盾装备）。
> 所有技能统一规则：最高 5 级，满级后从三选一候选中移除；
> 神庙"随机技能"强化可突破上限（理论最高 8 级）。
> 每级成长规则（2026-09-16 起）：属性词条每级累加数值；特效词条重复获得不重复挂载，
> 改为调用已拥有特效的 add_stack() 放大关键参数（策略见各 BulletEffect 子类 _on_stack_grown）。
> 下表"每级"列即每叠一层的增量，描述 = 基础值（Lv1）+ 每级增量。

## 四、装备·护盾（4 件，独立装备槽，非升级词条）

| equipment_id | 名称 | 基础耐久 | 掉率(普通/精英) | 特效（被击中触发） |
|---|---|---|---|---|
| `shield_basic` | 基础护盾 | 30/30 | 5% / 15% | 无特效 |
| `shield_poison` | 毒雾护盾 | 25/25 | 2% / 8% | 中毒：3秒每秒4点伤害 |
| `shield_frost` | 冰霜护盾 | 25/25 | 2% / 8% | 冰冻：移速40%、持续3秒 |
| `shield_reflect` | 反击护盾 | 20/20 | 2% / 8% | 反弹子弹/击退敌人 |

### 4.1 护盾叠层规则（2026-09-17 起）
1. **同类型叠加**：拾取相同 `shield_id` 的护盾叠加层数 +1（常规拾取最多 3 层），
   `max_hp` 和 `absorb_per_hit` 按层数翻倍（2层=2倍，3层=3倍，依此类推）。
2. **不同类型替换**：拾取不同 `shield_id` 的护盾替换为新类型，叠层重置为 1 层基础值。
3. **神庙强化突破上限**：神庙"随机护盾"选项给当前护盾叠层 +1~3 层，突破 3 层上限
   （理论最高 6 层），耐久立即补满到新的有效上限。
4. **回盾机制**：不受伤害 5 秒后自动回盾满值（5 秒内回满，无论护盾多大）；
   护盾破碎后 HUD 图标不消失，显示"回盾中..."直到回满。
5. **HUD 图标常驻**：装备护盾后图标常驻左上角，耐久为 0 时也保持显示（旧版会消失）。
   2 层以上名称后显示 `×N` 角标。

### 4.2 特效护盾 debuff 叠层（被击中触发，按护盾叠层放大；神庙强化突破 3 层后继续线性放大）

## 五、图标制作规范

### 5.1 文件要求
1. **格式**：PNG，必须为 **RGBA 带透明通道**（RGB 无 alpha 图经 Godot 默认通道重映射会整图透明）。
2. **尺寸**：正方形即可（本批原图 1024×1024），导入时 `.import` 已设 `process/size_limit=128` 控制显存；
   使用场景：HUD buff 图标 36px，三选一面板图标 22px，掉落物贴图 24px。
3. **命名**：直接用 ID，前缀 `icon_`，例如：
   - 技能：`icon_upg_damage.png`、`icon_upg_chainlightning.png`
   - 装备：`icon_shield_basic.png`
4. **放置目录**：`assets/art/ui/icons/`，按类型分四个子目录：
   `白色普通/`（普通技能7个）、`蓝色稀有/`（稀有技能11个）、`紫色史诗/`（史诗技能3个）、`灰色护盾/`（装备4个）。

### 5.2 视觉设计建议
1. 核心符号居中，四周留少量边距避免贴边裁切。
2. 稀有度区分靠**边框/光晕**（白/蓝/紫），图标本体保持高对比、小尺寸（22~36px）下仍可辨识。
3. 属性类可用抽象几何（刃=伤害、扳机=射速、靴=移速、心=血量）；
   特效类优先表达"命中反馈"（毒=液滴/骷髅、火=火焰、冰=雪花、闪电=折线、爆炸=星芒）。
4. 风格统一：建议同一描边粗细、同一光源方向、同一饱和度量级。

### 5.3 接入状态（已完成）
1. 加载统一走 `scripts/ui/IconLibrary.gd`：按 `icon_<id>.png` 路径契约自动加载（含正/负缓存与容错）。
2. 已接入三处：三选一卡片（LevelUpPanel 图标+文字）、HUD buff 图标（GameHUD 真实图标+层数角标）、
   护盾掉落物贴图（PickUp 图标替换色块）。
3. **新增图标零代码**：png 按 ID 命名放入对应稀有度目录即可自动显示，缺失时自动回退文字/色块。
